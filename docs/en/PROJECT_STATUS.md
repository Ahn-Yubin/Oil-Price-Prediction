# Project Status

This document is the quick map for understanding the current repository. It summarizes implementation scope, folder ownership, forecast-line generation, LLM status, models, backtesting, and the recommended next work.

## One-Line Summary

The project has been reorganized from an oil-only dashboard into a universal market forecasting platform. The FastAPI backend, `market_ai` domain logic, Vite frontend, CLI scripts, and model artifacts are separated. The chart displays yfinance market data and forecast quantile paths generated by price time-series models in a TradingView Lightweight Charts-style UI.

The LLM is not used for numeric forecasting. `LocalEventContextEncoder` deterministically vectorizes CSV/JSON event context, and `OpenAICompatibleLLMEventEncoder` can call an external chat completions endpoint only when both `ENABLE_EXTERNAL_LLM_CALLS=true` and `LLM_API_KEY` are set. No LLM path is allowed to generate or overwrite price, p50, p90, or return paths.

As of 2026-04-30, the model taxonomy is:

- Classical: `motif`
- Deep learning: `pattern_mlp`, `deep_lstm_tcn_fusion`, `llm_context_seq_moe`
- Baselines: `random_walk`, `drift`, `seasonal_naive`, `volatility_scaled_naive`
- Backtest-only: `flat`, `simple_moving_average_path`, optional `regime_ensemble`
- Removed/deprecated: `cycle`, `lstm`, `tcn`, `ensemble`

The `/api/forecast` `models` query is enforced. Removed models return 400 on the forecast API, while the `/api/chart` compatibility path can warn and fall back. `/api/chart` backward compatibility remains a requirement.

## How The Forecast Line Is Produced

The chart center forecast line is `ForecastResponse.forecast[].p50`.

1. The system fetches recent OHLC close prices from yfinance.
2. Close prices are transformed into log returns.
3. The selected forecasting paths are computed.
4. Default primary candidates are built from available artifacts. Deep models with missing artifacts are excluded from default candidates and recorded only in `artifact_status`.
5. The forecast target is a volatility-scaled cumulative log return distribution.
6. Prices are reconstructed with `current_price * exp(predicted_cumulative_log_return_h)`.
7. Quantile bands are built with a residual-volatility adapter.
8. Until rolling coverage is sufficiently measured, these bands must not be called validated confidence intervals.

The frontend renders p50, p10, p90, p05, p95, and bull/base/bear scenario overlays when `/api/forecast` succeeds. `/api/chart` fallback keeps the same basic fields, but removed models such as `cycle`, `lstm`, `tcn`, and `ensemble` are not reintroduced as active comparison models.

## Deep Training Commands

Production `1d/h45` base artifact:

```bash
python scripts/train/train_deep_fusion_models.py --model deep_lstm_tcn_fusion --interval 1d --universe oil_core --epochs 10 --batch-size 64 --force --no-llm-context
```

Event context MoE artifact:

```bash
python scripts/train/train_deep_fusion_models.py --model llm_context_seq_moe --interval 1d --universe oil_core --epochs 10 --batch-size 64 --force --llm-context --events-path data/external/events/sample_market_events.csv
```

Quick smoke artifact:

```bash
python scripts/train/train_deep_fusion_models.py --model deep_lstm_tcn_fusion --interval 1d --quick-test --epochs 1 --max-samples 128
```

No-event-context training:

```bash
python scripts/train/train_deep_fusion_models.py --model deep_lstm_tcn_fusion --interval 1d --universe oil_core --epochs 5 --batch-size 64 --force --no-llm-context
```

The training CLI does not silently use synthetic fallback after yfinance failure in production defaults. Synthetic data is allowed only with `--synthetic`, `--quick-test`, or explicit `--allow-synthetic-fallback`.

## LLM Status

The LLM is not a numeric price forecaster.

- The default is `ENABLE_LLM_CONTEXT=false`.
- `LocalEventContextEncoder` converts CSV/JSON event context into deterministic features.
- `OpenAICompatibleLLMEventEncoder` can call an external chat completions endpoint only when `ENABLE_EXTERNAL_LLM_CALLS=true` and `LLM_API_KEY` are set.
- In development, when LLM context is enabled without an API key, the mock encoder produces structured context only.
- LLM output does not generate or overwrite forecast price paths, p50, p90, or return paths.

## Warning Policy

`ForecastResponse.warnings: list[str]` is preserved for backward compatibility. New responses may include `warning_objects`, where each item has `code`, `severity`, `message`, and `action`.

- Artifact missing: shown as `warning` only when a user explicitly selects the deep model, with the required training command. Default dashboard load does not show missing deep artifacts as a yellow warning.
- Quantile uncalibrated: keeps the text `Quantile bands are residual-volatility adapters and are not validated coverage intervals yet.` but uses `info` severity.
- Data stale/fallback/mock: data quality problems use `warning` severity.

## Backtesting

Backtest entrypoint:

```bash
.venv/bin/python scripts/backtest/run_backtest.py --symbol CL=F --interval 1d --max-origins 5 --models random_walk,drift,motif,pattern_mlp --no-plots
```

Backtesting uses a walk-forward rolling origin design. Each origin uses only historical close values available at that origin, and selected models predict cumulative log return paths. Results are written as summary, horizon metrics, probabilistic metrics, leaderboard, and model availability CSVs. Missing deep artifacts should be recorded as unavailable for those models without failing the whole backtest.

## Implemented

- FastAPI routes are split under `backend/app/api/routes`.
- `/api/chart` backward compatibility is preserved.
- New `/api/forecast` contract is available.
- `warnings` is preserved and `warning_objects` is added as an optional additive field.
- Data status is surfaced as real, stale, fallback, mock, or error.
- Mock/fallback data policy is covered by settings and tests.
- Forecast target remains a volatility-scaled cumulative log return distribution.
- Interval-specific global `.npz` artifacts and metadata sidecars are separated.
- Deep model code paths, deep dataset, event context pipeline, `/api/forecast` models query, and `/api/models` availability are implemented.
- `--events-path` is now passed into the training dataset through `FileEventProvider`.
- yfinance market panel storage, EIA/CFTC/CME manual CSV ingest, daily event context build, and data manifest generation paths are available.
- The processed-data training CLI can accept market panels, oil fundamentals, COT, CME curves, and event context.
- Rolling leaderboard latest output and conformal calibration artifact paths are available.

## Current Limitations

- Full `1d/h45` artifacts for `deep_lstm_tcn_fusion` and `llm_context_seq_moe` exist, but at audit time they were still trained mostly on yfinance prices and sample event context rather than full real fundamentals/news coverage.
- Deep quick training is smoke validation only and does not imply production performance.
- Forecast band calibration paths and API wiring now exist, but bands remain unvalidated until enough rolling residuals are calibrated.
- `pattern_mlp` metadata is still marked `legacy_npz_v1`, and data hash, git commit, train_start, and train_end are empty.
- The cross-asset feature matrix can now accept processed market-panel and fundamental summaries, but current operating artifacts have not yet been long-trained on those expanded features.
- yfinance market panel cache/storage and EIA/CFTC/CME/manual CSV ingest paths are available, but actual long-history data loading must still be run.
