# Roadmap

The project starts with oil forecasting and expands toward a universal market AI platform.

## Next Steps

- Expand from oil futures to equities, ETFs, FX, crypto, rates, indices, and commodities.
- Strengthen provider abstraction and regularize data quality reports.
- Expand calibration, conformal intervals, and quantile coverage evaluation.
- Build production-grade LLM event ingestion while keeping numeric forecasts owned by time-series models.
- Gradually split the frontend into a Vite component structure as UI complexity grows.

## Principles to Preserve

- Preserve `/api/chart` compatibility until it is explicitly removed.
- Keep artifacts and metadata separate from source code.
- Update Korean source docs and English mirror docs together.
